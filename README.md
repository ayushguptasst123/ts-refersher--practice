## 🚀 Getting Started

To generate package.json
`npm init -y`

To install axios module
`npm install axios`

To build and run
`npx tsx file.ts`

### Bonus

- TypeScript code doesn’t run on the web directly; it is first compiled into JavaScript, and then that JavaScript file runs on the web.

- To convert TS file to JS
  `tsc hello.ts`

- Run the js file on node env
  `node hello.js`
